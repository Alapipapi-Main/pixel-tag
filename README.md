# PixelTag: Quick QR Creator

Build a modern website called PixelTag.

Branding (Apply Automatically)

Website name: PixelTag

Tagline: Create QR Codes in Seconds.

Design a unique, modern, minimalist brand identity.

Generate a professional logo and automatically use it throughout the website (header, footer, browser tab, loading screen, and metadata).

Generate and apply a matching favicon automatically. The favicon should be a simple rounded-square icon with a stylized white QR pattern on a blue gradient background, designed to remain recognizable at small sizes.

Use a consistent color palette, typography, spacing, and icon style across the entire website.

Goal

Create a simple, fast, and beautiful website that lets anyone generate QR codes instantly.

Design

Clean, modern, minimalist UI.

Fully responsive on desktop and mobile.

Dark and light mode.

Smooth animations.

Premium user experience.

Homepage

Place the QR generator in the center of the page.

Supported QR Types

Website URL

Text

Wi-Fi

Email

Phone Number

Features

Live QR code preview.

Customize QR color.

Customize background color.

Choose QR code size.

Download as PNG.

Copy the entered content.

Clear all fields.

Requirements

No sign-up or login required.

Automatically use the generated logo and favicon across the website.

Fast loading.

Responsive design.

SEO optimized.

Production-ready with no placeholder content.

Ensure every listed feature is fully functional.
